# Decodificador

Página para criptografar e descriptografar texto. Exercício de front-end da formação Alura.

As vogais são trocadas por códigos: `e` vira `enter`, `i` vira `imes`, `a` vira `ai`, `o` vira `obter` e `u` vira `ufat`. A página aceita apenas letras minúsculas, sem acento.

## Como abrir

Abra `index.html` no navegador. Não há instalação nem servidor obrigatório.
